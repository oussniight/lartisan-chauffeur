# L’Artisan Chauffeur

Site vitrine premium pour les services de chauffeur privé, transfert premium et transport de groupe.

## Features
- Hero premium avec branding luxueux
- Services, flotte, tarifs et avis clients
- Formulaire de réservation dynamique avec calcul du prix estimé
- Responsive design mobile
- Prêt pour publication GitHub Pages

## Déploiement GitHub Pages
1. Pousser ce dépôt sur GitHub
2. Aller dans Repo Settings > Pages
3. Sélectionner la branche `main` et le dossier racine `/`
4. Enregistrer

## Local preview
Ouvrir `index.html` dans un navigateur ou lancer un serveur local :

```bash
python -m http.server 8000
```

Puis ouvrir : http://localhost:8000
